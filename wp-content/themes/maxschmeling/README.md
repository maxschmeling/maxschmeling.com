# Max Schmeling WordPress theme

A custom classic WordPress theme for [maxschmeling.com](https://maxschmeling.com/), designed for a simple personal homepage and an editorial, technical blog.

## Setup

1. Deploy this repository to Pressable.
2. In WordPress, open **Appearance → Themes** and activate **Max Schmeling**.
3. Under **Settings → Reading**, select the `Home` page as the homepage and `Blog` as the posts page.
4. Under **Appearance → Menus**, assign menus to the Primary and Footer locations. If no primary menu is assigned, the theme provides a Blog / Projects / About fallback.

The homepage automatically displays the three latest posts. Any content added to the selected `Home` page appears below the built-in homepage sections.

The theme also provides a branded favicon automatically. If a Site Icon is later configured under **Settings → General**, WordPress uses that icon instead.

## Supported templates

- Front page
- Blog index
- Single posts and pages
- Category, tag, author, and date archives
- Search results
- Comments
- 404 page
